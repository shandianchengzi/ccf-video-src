# CCF 影视仓视频源

面向影视仓（TVBox / CatVod 接口）开发的个人学术视频源。

目标：原站年份、系列及排序筛选；视频查找；设备本地 CCF 登录；研究方向分类；GitHub Actions 维护公开视频目录，GitHub Pages 提供订阅。

## 设计边界

- Actions 只维护公开目录元数据，不下载或重新托管视频。
- 登录凭据只保存在用户自己的设备上，不进入仓库、构建产物或 Pages。
- 播放时遵守 CCF 原站账号权限，受限视频需要有效登录及相应访问资格。
- 此仓库初始为私有仓库；Pages 是否可用受 GitHub 套餐和仓库设置影响。

开发中。最终构建、验证结果和导入方法会随实现更新。
