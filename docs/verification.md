- CCF 筛选、列表和详情接口真实可访问；已比较免费与会员条目的权限响应。
- Python 测试涵盖服务器分页大小限制、重复页、异常空页、历史 ID 尾部空格、大整数 ID、历史年份、多分类、英文缩写边界及公共字段白名单。
